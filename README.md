
Skycast - Weather ForeCasting App
A modern, responsive weather application built with React and Vite that provides real-time weather information, forecasts, and condition tracking.

Features
Real-Time Weather Data: Search for current weather conditions by city or location.

Detailed Metrics: View humidity, wind speed, pressure, and visibility.

Forecasts: Access hourly and multi-day forecasts to plan ahead.

Responsive UI: Clean, intuitive interface optimized for both desktop and mobile devices.

Tech Stack
Frontend: React, JavaScript, Vite

Styling: CSS

Deployment: GitHub Pages
